## Plugin metadata

Plugin metadata here means the data of each plugin kept under this repository's `plugins/` source directory. Since most plugins start with `dsh-xx`, the first six characters are used as the leading index directory. For plugins that do not start with that prefix, the first two characters are used as the leading index directory instead.

The metadata layout is modelled on [nixpkgs](https://github.com/NixOS/nixpkgs/tree/master/pkgs/by-name) and [nix-packages](https://github.com/Mooling0602/nix-packages/tree/main/pkgs/by-name).

For the exact parsing rules and content design, see the [documentation](DOCS.md).

## dsh-mloader-plugins

These are the plugins supported by [dsh-mloader](https://github.com/Mooling0602/dsh-mloader) that are independent of DSH itself. They do not use DSH's own plugin management system, and they are not part of the mynpm.staringplanet.top index and redirect service.

> Since upstream is still under development, no stable release is available yet.

- [dsh-credentials-helper](https://github.com/Mooling0602/dsh-credentials-helper)

## Plugin list (DSH plugins - TypeScript/JavaScript)

You can subscribe to and install the plugins listed here through this custom plugin index source. Plugins I did not develop myself are welcome too, so feel free to open a PR!

```plaintext
https://mynpm.staringplanet.top/dsh-plugins/index.json
```

Because the index source comes with an npm conversion service, not every feature is available (such as viewing plugin download counts or GitHub star counts), but basic information viewing and plugin management work fully.

If the number of plugins grows too large later, the list may be split into a separate document.

> [!TIP]
> Developers who distribute their plugins as GitHub release tarballs are encouraged to PR their own plugin metadata to this repository, which brings the same index and request redirect service and saves users the trouble of repeatedly copying a new plugin package link into DSH by hand.
>
> As an ordinary user, you may also want to install [dsh-better-plugin-updater](https://github.com/Mooling0602/dsh-better-plugin-updater) to manage plugins that DSH's own plugin package update system does not support (GitHub sources, for example).
